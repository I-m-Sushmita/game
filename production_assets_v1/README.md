# CITY OF MONSOON — Production Assets v1

A production-oriented environment pack for the 2D side-scrolling Godot game. The visual direction is cinematic modern-Indian pixel art with monsoon rain, wet reflections, warm street lighting, layered city depth and subtle environmental motion.

## Main folders
01 Tilesets — road/wet-road/bridge/waterfront atlas + prototype tile chunks.
02 Buildings — modular buildings, facade pieces, doors/windows/stairs references.
03 Interiors — room, home, classroom, cafe/canteen and mechanic-shop scene crops.
04 Nature — trees, bushes, flowers, rocks and extracted transparent sprites.
05 Props — traffic lights, lamps, signs, furniture, bins, machines and city details.
06 Vehicles — buses, cars, taxi, auto-rickshaw, van, motorcycle and scooter scene sprites.
07 Animated Elements — source atlas plus game-ready PNG strips for tree sway, grass sway, leaves, puddles, water flow, neon and windows.
08 VFX Weather — weather atlas plus rain, fog and lightning strips.
09 Lighting — reference panel + radial Light2D textures/headlight cone.
10 Parallax Backgrounds — separated sunset and rainy-night horizontal background layers.
11 UI Elements — UI reference + starter transparent icons.
12 Templates & Scenes — environment story/location templates.
13 Documentation — preview, manifests, animation metadata and Godot import guide.

## Important production note
AI-generated sprite sheets are a strong visual/prototyping base, but before final release you should perform pixel cleanup, consistent scale alignment, collision authoring and any exact typography redraws.
